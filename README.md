# Gestor de Gastos Personales

Aplicación de consola desarrollada en Python para registrar y consultar ingresos y gastos personales.

## Funcionalidades

- Registrar ingresos.
- Registrar gastos y clasificarlos por categoría.
- Validar los montos ingresados.
- Consultar el saldo actual.
- Consultar el historial de movimientos.
- Generar un resumen mensual de ingresos, gastos y balance.
- Guardar los movimientos en un archivo de texto para conservar los datos entre ejecuciones.

## Tecnologías

- Python 3
- Manejo de archivos de texto
- Funciones y estructuras de control
- Manejo de excepciones

## Requisitos

Tener Python 3 instalado.

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir una terminal en la carpeta del proyecto.
3. Ejecutar:

   """bash
   python3 main.py
   """

## Uso

El programa presenta un menú interactivo que permite registrar movimientos, consultar el saldo, revisar el historial y consultar resúmenes mensuales.
